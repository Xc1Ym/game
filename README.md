# 果园连连看

一个零依赖、响应式的水果主题连连看游戏。

## 运行

电脑已安装 Node.js，可直接执行：

```bash
npm start
```

然后访问终端显示的 `http://127.0.0.1:4173`。

## 测试

```bash
npm test
```

## 玩法

- 点击两个相同水果；它们之间能用不超过两次转弯的线连接时即可消除。
- 可从“悠闲、进阶、挑战”三档难度中选择。
- 三档限时分别为 4、5、6 分钟；棋盘规模分别为 6×8、8×10、10×12。
- 难度越高，水果种类越多、提示和洗牌次数越少；挑战模式包含全部 24 种水果。
- 提示会高亮一组可消除水果，洗牌会重新排列剩余水果。
- 连续 3 秒内消除可累积连击加分；完成后按剩余时间获得奖励。
- 本机排行榜按难度记录不同玩家的最佳通关时间，同用时按得分排序；数据保存在当前浏览器中。

## 美术素材

24 种水果使用项目内置的原创卡通 PNG 素材，不依赖系统 emoji。两张完整图集在
`assets/fruits/fruit-atlas.png` 和 `assets/fruits/fruit-atlas-extra.png`，可用
`npm run assets:crop` 重新裁切各个水果图标。
