# 果园游戏屋

一个零依赖、响应式的水果主题小游戏合集。首页是一台可操作的街机，支持触控摇杆、方向键和 WASD 选择游戏，当前已开放水果连连看，果园扫雷、接水果和水果合成正在规划中。

## 运行

电脑已安装 Node.js，可直接执行：

```bash
npm start
```

然后访问终端显示的 `http://127.0.0.1:4173`。

水果连连看位于 `games/link-link/`，从合集首页可直接进入；排行榜仍使用同一域名的浏览器存储，迁移路径不会清除已有成绩。

## 测试

```bash
npm test
```

## 玩法

- 点击两个相同水果；它们之间能用不超过两次转弯的线连接时即可消除。
- 消除动画期间可继续点击其他水果，连续配对无需等待动画结束。
- 可从“悠闲、进阶、挑战”三档难度中选择。
- 三档限时分别为 4、5、6 分钟；棋盘规模分别为 6×8、8×10、10×12。
- 难度越高，水果种类越多、提示和洗牌次数越少；挑战模式包含全部 24 种水果。
- 提示会高亮一组可消除水果，洗牌会重新排列剩余水果。
- 连续 3 秒内消除可累积连击加分；完成后按剩余时间获得奖励。
- 选中两块但无法消除时扣 5 分，并中断当前连击；重复点击同一块取消选择不会扣分。
- 本机排行榜按难度保留总积分最高的 10 局通关成绩（包含时间奖励），同分时用时短的优先，再相同则较早完成的优先；同一玩家可多次上榜。当前浏览器中已有的成绩也会按此规则重新排序。

## 美术素材

24 种水果使用项目内置的原创卡通 PNG 素材，不依赖系统 emoji。两张完整图集在
`assets/fruits/fruit-atlas.png` 和 `assets/fruits/fruit-atlas-extra.png`，可用
`npm run assets:crop` 重新裁切各个水果图标。
